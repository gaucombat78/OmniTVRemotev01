# OmniRemote — 100% Free Zero-Cloud Universal Smart TV Remote

OmniRemote is a completely open-source, local-network TV remote for Android and Web.
It runs 100% on LAN with **zero cloud brokers, zero paid subscriptions, and zero tracking**.

## Supported Smart TVs & Streaming Devices
- **Roku Streaming Sticks & Roku TVs** (ECP REST Protocol on port 8060)
- **LG webOS Smart TVs** (SSAP WebSocket Secure Protocol on port 3000)
- **Samsung Tizen Smart TVs** (Tizen WSS Protocol on port 8002)
- **Sony Bravia 4K / Google TV** (REST IRCC on port 80)
- **Amazon Fire TV Sticks & Omni TVs** (DIAL Protocol on port 8008)
- **Android TV / Chromecast with Google TV** (Cast / DIAL on port 8008)
- **Vizio SmartCast TVs** (REST Protocol on port 7345)

## Included Fast-Access Apps
- **Amazon Prime Video** (One-click launch & search)
- **Netflix**
- **YouTube**
- **Spotify**

## How to Build the APK
1. Create a free repo on GitHub.
2. Push this project code.
3. GitHub Actions builds your APK automatically under **Actions -> Artifacts**.
